# 🚀 Code Samples Collection

> A curated collection of algorithms, data structures, and programming patterns across multiple languages.

## 📚 Overview

This repository contains practical implementations of common algorithms, data structures, and programming concepts.

## 🗂️ Languages & Projects

### **C** 
Core data structures including B-trees, linked lists, and string utilities with custom implementations.

### **C++**
Classic algorithms and patterns: Fibonacci, recursion, inheritance, lists, and stack implementations.

### **Go**
Modern Go patterns and concurrency examples:
- Channels & concurrency patterns
- Command dispatcher architecture
- OOP-like patterns in Go
- Task worker API
- Practice exercises

### **JavaScript**
Algorithm implementations including:
- Linked lists & trees (AVL, BST)
- Graph algorithms (BFS, DFS)
- Sorting algorithms
- LeetCode-style problems

### **Node.js**
A simple Express.js server with routes demonstrating async patterns:
- `GET /` – Basic hello message
- `GET /wacky` – Random funny phrase with simulated async delay
- `GET /quote` – Fetches a random quote from zenquotes.io (async/await)
- `GET /quote-resolve` – Same as above using promise chaining

### **PHP**
Utility functions: Fibonacci, Hamming weight, array intersections.

### **Python**
Variety of examples: bit manipulation, classes, Fibonacci, prime numbers, and simple cart implementation.
